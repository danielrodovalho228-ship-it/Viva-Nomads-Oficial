# Fontes locais

Arquivos .woff2 (subconjunto latin, cobre português) das famílias Inter, Plus Jakarta Sans,
JetBrains Mono e Unbounded, obtidos do pacote @fontsource (licença SIL Open Font License 1.1).
Ficam no repositório para o build não depender de fonts.googleapis/gstatic (deploy do #406 caiu por isso).
